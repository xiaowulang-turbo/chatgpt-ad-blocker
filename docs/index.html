安装

已上架 Chrome 应用商店，一键安装即可

从 Chrome 应用商店安装

在 Chrome 中打开商店页，点击右上角「添加至 Chrome」即可。自动更新、自动同步。

开发者模式加载（可选，无需商店）
打开扩展管理页 在 Chrome 地址栏输入 chrome://extensions，右上角开启「开发者模式」
加载已解压的扩展程序 点击「加载已解压的扩展程序」，选择源码目录 chatgpt-ad-blocker/
开始使用 打开或刷新 chatgpt.com 会话页，广告卡片即被自动屏蔽
